# 1. Назначение проекта

Создание современной веб-платформы, предназначенной для удобного выбора и покупки товаров для дома. Сервис объединяет удобный каталог, систему корзины и личные кабинеты пользователей, предоставляя полный цикл онлайн-покупки домашней утвари.

# 2. Ключевые функциональные модули

### Модуль корзины и заказов

Полноценная корзина с возможностью изменения количества товаров, автоматическим пересчетом итоговой стоимости и оформлением заказов с указанием адреса доставки.

### Модуль пользовательской системы

Регистрация и авторизация.

### Модуль обратной связи

Форма связи с валидацией данных и интеграция с Telegram API для мгновенного получения уведомлений от пользователей.

# 3. Ожидаемый результат

Удобный и интуитивно понятный веб-сервис для покупки домашней утвари, который позволяет пользователям быстро находить нужные товары, добавлять в корзину и оформлять заказы с минимальным количеством действий.

# Выработка требований

1. Как отец молодой семьи, я хочу просматривать товары по категориям и фильтровать их по цене, чтобы быстро найти подходящую посуду или текстиль в рамках моего бюджета.
   • Пользователь может выбрать категорию из списка (например, "Кухня", "Ванная", "Текстиль").
   • Система отображает список товаров в выбранной категории с фото, названием, ценой и рейтингом.
   • Доступна фильтрация товаров по ценовому диапазону.
2. Как администратор магазина, я хочу управлять каталогом товаров: добавлять новые позиции, загружать изображения, изменять цены и описания, чтобы поддерживать ассортимент актуальным.
   Критерии готовности:
   • В административной панели доступна форма создания товара с полями: название, описание, цена, категория.
   • Реализована возможность загрузки изображения товара с локального компьютера.
   • Система сохраняет изображение на сервере и автоматически формирует URL для доступа к нему.
   • После создания товар сразу появляется в каталоге без необходимости дополнительных действий.
   • Администратор может удалять товары из каталога, при этом товар исчезает из общего доступа.
3. Как покупатель, я хочу иметь возможность связаться с администрацией магазина через форму обратной связи, чтобы задать вопросы или оставить отзыв.
   Критерии готовности:
   • На отдельной странице доступна форма обратной связи с полями: имя, email, тема, сообщение.
   • Все поля проходят валидацию (имя не менее 2 символов, корректный email, сообщение не пустое).
   • После отправки формы сообщение доставляется в Telegram-чат администрации.
   • Пользователь получает уведомление об успешной отправке сообщения.

# Разработка архитектуры и детальное проектирование

### Характер нагрузки на сервис

        ◦ Соотношение R/W нагрузки: 90/10

Чтение (90%): Пользователи активно листают каталог товаров и изучают карточки товаров.
Запись (10%): происходит при регистрации и авторизации, управлении корзиной и оформлении заказов.
◦ Объемы трафика
Входящий: невысокий, в основном запросы от клиента, заполнение различных форм.
Исходящий: высокий, сервер отдает клиенту множественные массивы данных, множество различных позиций при просмотре каталога.
